In 2016, a question was asked: How many trick-or-treaters typically come through
our neighborhood? I wanted to be able to answer it, but we hadn't kept track of
it the previous year. So, I started keeping track.

Each year, since Halloween 2016, I record the number of trick-or-treaters who
come to our house in one-minute intervals from 18:00 to 21:00. The separate .csv
files in the `input` folder are those recordings.

After having recorded the first year's data, I wanted to know more than just the
total number, so I also wrote up some R code (`Halloween.R`) to produce a few
different visualizations of the data. Those files are in the `output` folder.
